FINSENTINELS — LOCAL START
=========================

To start the local app, double-click run.bat in this folder. It starts or
reuses the FastAPI backend, starts the secured Next.js workspace, waits for the
login page, and opens it in your browser at http://127.0.0.1:3000/login.

Keep the API and frontend terminal windows open while using FinSentinels. Close
those windows when you are done.

For first-time setup only, if frontend/.env.local does not exist, run
frontend/setup-local-login.ps1 and choose your analyst username and password.
Do not rerun setup unless you intend to replace those credentials. Keep
frontend/.env.local and backend.local.env private; do not commit them.

The bundled 99-account graph is synthetic demo data. The OBP bank connector is
available after an authorized provider connection is configured.
