FINSENTINELS — LOCAL START
=========================

The analyst workspace uses the secured Next.js interface. The old static demo
login has been retired; there is no shared demo access code.

1. Start FastAPI in one PowerShell window from this project directory:
   .\.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload

2. Start Next.js in a second window:
   cd frontend
   pnpm dev

3. Open the URL printed by Next.js (normally http://127.0.0.1:3000/).

Local analyst login:
   Username: analyst
   Password: see frontend/.env.local created for this workspace

Do not commit frontend/.env.local or reuse this local password in production.

The bundled 99-account graph is a synthetic workspace dataset. The OBP bank
connector is available after an authorized provider connection is configured.
